# UsagiMinesweeper
# 乌萨奇扫雷
一款为**乌萨奇宝宝**和它的好朋友们打造的治愈系扫雷小游戏。
## 游戏介绍
- 通过游戏获取积分，可兑换专属乌萨奇表情照  
- 兑换后的表情会在游戏过程中、扫雷成功时为你祝贺，失败时温柔鼓励你，全程暖心陪伴  
- 每一次点击都有乌萨奇的超绝叫声～
- 目前已实现普通模式玩法，更多玩法还在开发中...
